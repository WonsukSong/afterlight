# Afterlight

An independent AI briefing with Daily, Weekly and Papers collections. The Papers collection explains previous limitations, new mechanisms and concise results across models, AI systems, optimization and AI chips. It publishes at most one sourced brief per Pacific day; retrospective selections are labeled.

This repository contains the public GitHub Pages distribution. It reads published content from the Afterlight service and keeps a bundled snapshot. The hourly Actions workflow validates the public feed, commits changed content and deploys Pages. No writer credentials or editor drafts are included. Built from Afterlight source commit `63ae951113011b7de7e847b5a500e3a5251f829f`.

Useful paper visuals include sourced explanatory schematics and credited, licensed original figures, with full-size image links.
