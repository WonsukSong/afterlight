# Afterlight

An independent AI briefing with Daily, Weekly and Papers collections. The Papers collection explains previous limitations, new mechanisms and concise results across models, AI systems, optimization and AI chips. It publishes at most one sourced brief per Pacific day; retrospective selections are labeled.

This repository contains the public GitHub Pages distribution. It reads published content from the Afterlight service and keeps a bundled snapshot. The hourly Actions workflow validates the public feed, commits changed content and deploys Pages. No writer credentials or editor drafts are included. Built from Afterlight source commit `3346a0152cf715522ee46213f9ca9c5bf77197bd`.
